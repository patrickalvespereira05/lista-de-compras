LISTA DE COMPRAS — MODO OFFLINE

1. Publique estes arquivos no GitHub Pages (ou outro servidor HTTPS).
2. Abra o aplicativo uma vez com internet no celular.
3. Instale pela opção “Instalar aplicativo” / “Adicionar à tela inicial”.
4. Depois do primeiro carregamento completo, a interface fica disponível offline.
5. Os produtos e listas continuam salvos no próprio dispositivo usando armazenamento local.

IMPORTANTE: abrir o index.html diretamente como arquivo (file://) não ativa Service Worker. Para o modo offline do PWA, use HTTPS ou localhost.
